## WhatsApp Catalog Setup Notes

1. **Collection Images:** Use relevant authority logos or service-related imagery for each collection cover image.
2. **Item Images:** Use the Wasleen icon or authority logos as product images for each item.
3. **Item Prices:** WhatsApp catalog allows price display. Consider showing "Contact for pricing" or indicative ranges.
4. **Item Descriptions:** The descriptions above are short. For actual WhatsApp catalog entries, expand each to 2-3 sentences highlighting key benefits.
5. **Catalog Structure:** Each item should include:
   - **Name** (short, descriptive title)
   - **Description** (2-3 sentences, customer-focused)
   - **Price** (optional — can show range or "Contact us")
   - **Link** (link to the corresponding page on the website for more details)
6. **WhatsApp Catalog Limits:** Up to 500 items per catalog, up to 30 collections.
